# Coding Practice

A multi-language programming practice repository covering algorithms, data structures, language fundamentals, and problem-solving exercises.

## Languages

- **C++** - competitive-programming patterns and algorithms
- **Java** - object-oriented programming and problem solving
- **Python** - concise implementations and experimentation

## Structure

Exercises are grouped by language in the `c++`, `java`, and `python` directories. Browse the relevant directory to explore examples and practice solutions.

## Running an exercise

Use the compiler or interpreter for the language of the selected file. Individual exercises are intentionally kept small so they can be run and modified independently.
